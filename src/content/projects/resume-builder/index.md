一个功能完整的在线简历生成工具，左侧编辑、右侧实时预览，支持多种模板、字体和中英双语切换。

## 功能亮点

- **4 套专业模板** — 极简黑白、蓝色现代、深色强调、双栏布局，一键切换
- **8 种字体** — 思源黑体、宋体、衬线、Inter、DM Sans、Lato、Raleway、Mono
- **实时预览** — 左侧编辑，右侧 A4 纸张尺寸实时渲染
- **中英双语** — 一键切换中文/英文界面和内容
- **导出 PDF / HTML** — 一键导出打印级 PDF 或独立 HTML 文件
- **10 种主题色** — 绿色、蓝色、紫色、青色等，自由搭配
- **字号颜色微调** — 姓名、标题、正文、辅助信息独立调节
- **智能字数提示** — 自我评价等字段实时提示最佳字数范围
- **模块开关** — 教育、工作、项目、技能、奖项等模块按需显示

## 技术栈

- 纯前端 HTML + CSS + JS，零后端依赖
- TailwindCSS 原子化样式
- Google Fonts 多字体加载
- 浏览器原生打印导出 PDF

## 设计理念

让写简历回归本质——专注于内容本身，而不是排版。所有样式调整都在可视化界面完成，无需手动调 CSS。
