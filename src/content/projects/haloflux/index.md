全屏、节拍驱动的科幻数据可视化。中心是编织状光场，外面一圈微型数据面板，环外有多层向外迸发的光束。

**HALOFLUX by Ryder191**（RYDER CODE / Ms MAIKEBAIs CAT）

源码与许可证：[github.com/Ryder191/haloflux](https://github.com/Ryder191/haloflux)

## 怎么看

- 桌面打开控制台版，手机打开适配版
- 双击画面或按 F 全屏
- 右上角 CONSOLE 或按 C 打开调参
- 背景音乐在第一次点击后播放
