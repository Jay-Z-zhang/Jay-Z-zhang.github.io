## 为什么单位经济模型最重要？

很多创业公司失败，不是因为没客户，而是因为**每做一个客户都亏钱**——却幻想靠规模效应扭亏为盈。

在竞争激烈的市场，**验证单位经济模型是生存的前提**。

---

## 核心公式

```
LTV / CAC ≥ 3
```

- **CAC**（Customer Acquisition Cost）= 获客成本
- **LTV**（Lifetime Value）= 用户终身价值（毛利润，不是收入！）

**健康标准：** 每花 1 块钱获客，至少赚回 3 块钱毛利润。

### 常见错误

> **用收入代替毛利润计算 LTV**
>
> 收入 - 运营成本 = 毛利润
>
> 如果你的毛利率只有 30%，那 LTV 要除以 3 才是真实值。

---

## CAC 的分母陷阱

### 表面成本 vs 真实成本

**表面 CAC：**
```
广告花费 / 新增付费用户数
```

**真实 CAC（Fully Loaded CAC）：**
```
（广告花费 + 销售工资 + 营销团队工资 + 工具费用 + 办公分摊）/ 新增付费用户数
```

### 真实 CAC 包含什么？

| 成本项 | 说明 |
|--------|------|
| **人员成本** | 销售工资、提成、营销团队薪资 |
| **运营成本** | 内容创作、活动费用 |
| **软件费用** | CRM、营销自动化工具 |
| **分摊费用** | 房租、差旅 |

### 市场竞争风险

> 在竞争激烈的市场，获客成本**必然上升**。
> 
> 财务模型必须预判这一点，而不是用当前的低成本做假设。

---

## LTV 的分子幻觉

### 高估留存的致命错误

**早期公司的正确做法：**
> 只计算 12-24 个月内的价值，不要假设长期留存。

**原因：**
- 没有历史数据支撑长期预测
- 市场变化快，用户行为会变
- 过度乐观 = 自欺欺人

### 资金时间价值

> 未来的钱不等于现在的钱。
> 
> 考虑通胀和资金成本，5 年后的 100 块可能只值今天的 70 块。

**计算公式：**
```
折现 LTV = 未来收益 / (1 + 折现率)^年数

折现率通常取 10-20%
```

## 回本周期（Payback Period）

### 为什么比 LTV/CAC 更重要？

> 对于创业公司，**多长时间能收回获客成本**，比整体比例更关键。

### 计算公式

```
回本周期（月）= 完全加载 CAC / 用户月毛利润
```

### 基准参考

| 回本周期 | 评级 | 行动建议 |
|----------|------|----------|
| **≤ 6 个月** | 优秀 | 可以放心放大投放 |
| **12 个月** | 可接受 | 谨慎扩张 |
| **> 18 个月** | 危险 | 现金流断裂风险极高 |

### 优化技巧

> **年付预收**：让用户一次性付一年费用
> 
> 效果：回本周期从 12 个月缩短到 1 个月

---

## 压力测试：3 个反向思考问题

### 问题 1：如果流失率翻倍会怎样？

```
原假设：月流失率 5% → LTV = 20 个月
压力测试：月流失率 10% → LTV = 10 个月

LTV/CAC 从 4 降到 2 → 从健康变成危险
```

### 问题 2：如果竞争对手推出免费方案？

```
获客成本可能翻倍
回本周期可能从 12 个月延长到 24 个月
```

### 问题 3：自然流量和付费流量是否混在一起算？

```
正确做法：分开计算
- 自然流量 CAC（低）
- 付费流量 CAC（高）

混在一起算会低估真实获客成本
```

## 行动清单

### 1. 计算真实 CAC

```
完全加载 CAC = 
  （上月所有销售 + 营销费用）/ 上月新增付费用户数
```

### 2. 计算回本周期

```
回本周期 = 完全加载 CAC / 用户月毛利润

如果 > 15 个月 → 立即调整定价或降低成本
```

### 3. 做压力测试

```
假设留存时间减半
重新计算 LTV/CAC
如果 < 3 → 商业模式需要调整
```

---

## 一句话总结

> **不健康的单位经济模型意味着：规模越大，亏损越大。**
> 
> **创始人必须避免低估获客成本、高估终身价值。优先关注现金回收时间，而非追逐表面比例。**
