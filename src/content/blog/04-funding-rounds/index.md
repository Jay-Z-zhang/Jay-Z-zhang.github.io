## 为什么要理解融资轮次？

融资不是「缺钱了找投资人」那么简单。每一轮融资的目的、对象、金额、估值逻辑都不同。

理解融资轮次，帮你：
- **知道什么时候该融钱**
- **知道该找谁融钱**
- **知道该融多少**
- **知道估值怎么算**

---

## 三大投资类型

### 天使投资人（Angel Investor）

| 特征 | 说明 |
|------|------|
| **阶段** | 最早期，只有一个想法或原型 |
| **金额** | 小额（通常 < 100 万） |
| **来源** | 个人（成功创业者、高管、富人） |
| **退出** | 通常在下一轮融资后退出 |

### 风险投资（VC）

| 特征 | 说明 |
|------|------|
| **阶段** | 早中期，已有产品和初步验证 |
| **金额** | 中大额（100 万 - 数亿） |
| **来源** | 专业基金（如红杉、高瓴） |
| **退出** | IPO 或被收购 |

### 私募股权（PE）

| 特征 | 说明 |
|------|------|
| **阶段** | 后期，准备上市 |
| **金额** | 大额（数亿 - 数十亿） |
| **来源** | 专业基金（如KKR、黑石） |
| **退出** | IPO 后二级市场卖出 |

## 融资轮次详解

### 种子轮（Seed Round）

```
阶段：只有一个想法
金额：10-50 万
投资人：家人、朋友、天使投资人
用途：组建团队、做原型
```

**核心任务：** 证明「这个想法值得做」

---

### 天使轮（Angel Round）

```
阶段：有原型，没验证
金额：100-500 万
投资人：天使投资人、早期基金
用途：产品开发、早期用户获取
```

**核心任务：** 证明「有人愿意用」

---

### A 轮（Series A）

```
阶段：有产品，有初步数据
金额：1000 万 -1 亿
投资人：VC
用途：完善产品、扩大团队、验证商业模式
```

**核心任务：** 证明「商业模式可行」

**关键指标：**
- 用户留存率 > 40%
- 月增长 > 20%
- 清晰的变现路径

---

### B 轮（Series B）

```
阶段：模式验证成功，需要快速扩张
金额：1 亿 -5 亿
投资人：VC、成长型基金
用途：市场扩张、团队扩充、技术升级
```

**核心任务：** 证明「可以快速复制」

**关键指标：**
- 收入快速增长（月环比 > 30%）
- 单位经济模型健康（LTV/CAC > 3）
- 市场份额开始领先

---

### C 轮（Series C）

```
阶段：行业领先，准备上市
金额：5 亿 -20 亿+
投资人：PE、大型 VC、战略投资人
用途：进一步扩张、并购、准备 IPO
```

**核心任务：** 证明「能成为行业龙头」

**关键指标：**
- 市场前三
- 持续盈利或清晰盈利路径
- IPO 可行性

---

### 后续轮次（D、E、F...）

```
阶段：已经很大，但还需要更多钱
金额：无上限
投资人：PE、主权基金、大型机构
用途：国际化、并购、延迟上市
```

**注意：** 不是每家公司都需要 D 轮。如果 C 轮后能上市，就直接 IPO。

## 为什么要分轮次融资？

### 1. 投资人限制

> 不同基金只能投特定阶段。种子基金不能投 B 轮，PE 基金不能投种子轮。

### 2. 资金使用效率

> 早期公司拿太多钱 = 浪费。因为你还没找到正确的方向，钱多了反而会乱花。

### 3. 估值和稀释

> 早期估值低，融太多 = 稀释太多股权。分轮次融资，每轮估值更高，稀释更少。

**举例：**

| 方案 | 种子轮 | A 轮 | 总融资 | 总稀释 |
|------|--------|------|--------|--------|
| **一次性融** | - | 2000 万@1 亿估值 | 2000 万 | 20% |
| **分轮次融** | 200 万@2000 万估值 | 1800 万@1 亿估值 | 2000 万 | 10% + 15% = 23.5% |

看起来分轮次稀释更多？但注意：
- 种子轮 200 万帮你验证了方向
- A 轮估值从 2000 万涨到 1 亿，证明了你做对了

## 融资全流程

```
1. 准备阶段
   ├── 完善产品/数据
   ├── 准备 BP（商业计划书）
   ├── 确定目标投资人
   └── 找 FA（财务顾问）

2. 路演阶段
   ├── 见 20-50 个投资人
   ├── 收到 3-5 个 TS（投资意向书）
   └── 选择最优条款

3. 尽调阶段
   ├── 投资人做业务尽调
   ├── 投资人做法务尽调
   └── 投资人做财务尽调

4. 签约阶段
   ├── 签署 SHA（股东协议）
   ├── 完成工商变更
   └── 钱到账
```

## 估值怎么算？

### 早期公司（种子/A 轮）

**方法：可比公司法**

```
找 3-5 个类似阶段、类似赛道的公司
看他们融资时的估值
取中位数作为参考
```

### 成长期公司（B/C 轮）

**方法：收入倍数法**

```
估值 = 年收入 × 倍数

倍数参考：
- SaaS：5-15x
- 电商：1-3x
- 硬件：0.5-2x
```

### 成熟公司（C 轮后）

**方法：DCF（现金流折现）**

```
预测未来 5 年现金流
用折现率（通常 10-20%）折算到现在
```

## 常见坑

### 1. 估值过高

> 估值太高 = 下一轮融资困难（投资人觉得贵）
> 
> **建议：** 估值合理偏低，给下一轮留空间

### 2. 稀释过多

> 每轮稀释 15-25% 是合理的
> 
> **警惕：** 如果单轮稀释 > 30%，说明你议价能力太弱

### 3. 条款陷阱

> 注意对赌条款、清算优先权、反稀释条款
> 
> **建议：** 请专业律师审核

## 一句话总结

> **融资不是目的，是手段。每一轮钱都应该帮你到达下一个里程碑。**
