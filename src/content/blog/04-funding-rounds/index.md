## 从一个真实问题说起

经常有创业者问我：

> 「我的项目刚有个想法，该找谁融资？融多少？估值怎么算？」

这个问题背后其实有 3 个子问题：
1. **什么时候该融钱？**
2. **该找谁融钱？**
3. **该融多少、估值怎么定？**

这篇文章帮你一次性搞清楚。

---

## 先理解三大投资类型

在讲具体轮次之前，先搞清楚谁在给钱。

### 天使投资人（Angel Investor）

**一句话：** 用个人资金投早期项目的富人。

| 特征 | 说明 |
|------|------|
| **阶段** | 最早期，只有一个想法或原型 |
| **金额** | 小额（通常 < 100 万） |
| **来源** | 成功创业者、企业高管、富裕个人 |
| **动机** | 财务回报 + 帮助创业者 + 行业兴趣 |
| **退出** | 通常在下一轮融资后退出 |

**特点：**
- 决策快（个人决定，不需要投委会）
- 金额小（不会改变公司股权结构）
- 除了钱，还能提供人脉和经验

### 风险投资（VC）

**一句话：** 用基金的钱投成长期项目的专业机构。

| 特征 | 说明 |
|------|------|
| **阶段** | 早中期，已有产品和初步验证 |
| **金额** | 中大额（100 万 - 数亿） |
| **来源** | 专业基金（如红杉、高瓴、经纬） |
| **动机** | 财务回报（基金有存续期，通常 10 年） |
| **退出** | IPO 或被收购 |

**特点：**
- 决策慢（需要投委会审批）
- 金额大（可能改变公司股权结构）
- 除了钱，还能提供战略指导和资源

### 私募股权（PE）

**一句话：** 用大额资金投后期项目的机构。

| 特征 | 说明 |
|------|------|
| **阶段** | 后期，准备上市 |
| **金额** | 大额（数亿 - 数十亿） |
| **来源** | 专业基金（如 KKR、黑石） |
| **动机** | 财务回报（优化公司治理后上市退出） |
| **退出** | IPO 后二级市场卖出 |

**特点：**
- 关注盈利和现金流
- 可能要求董事会席位
- 参与公司治理优化

## 融资轮次详解

### 种子轮（Seed Round）

```
阶段：只有一个想法
金额：10-50 万
投资人：家人、朋友、天使投资人
用途：组建团队、做原型
```

**核心任务：** 证明「这个想法值得做」

**具体要做什么：**
- [ ] 写一份简单的商业计划书（BP）
- [ ] 做一个产品原型（哪怕是 Figma 设计稿）
- [ ] 找到 10 个愿意试用的人
- [ ] 收集他们的反馈

**估值参考：** 500 万 - 2000 万

**常见陷阱：**
> 种子轮融太多钱 = 浪费。因为你还没找到正确的方向，钱多了反而会乱花。

---

### 天使轮（Angel Round）

```
阶段：有原型，没验证
金额：100-500 万
投资人：天使投资人、早期基金
用途：产品开发、早期用户获取
```

**核心任务：** 证明「有人愿意用」

**具体要做什么：**
- [ ] 完成产品开发（MVP）
- [ ] 获取 100-1000 个早期用户
- [ ] 验证留存率（7 日留存 > 30%）
- [ ] 找到初步的变现路径

**估值参考：** 2000 万 - 5000 万

**投资人会问什么：**
- 「你的用户是谁？」
- 「他们为什么用你的产品？」
- 「留存率怎么样？」
- 「怎么赚钱？」

---

### A 轮（Series A）

```
阶段：有产品，有初步数据
金额：1000 万 -1 亿
投资人：VC
用途：完善产品、扩大团队、验证商业模式
```

**核心任务：** 证明「商业模式可行」

**关键指标：**
- 用户留存率 > 40%
- 月增长 > 20%
- 清晰的变现路径
- 单位经济模型初步验证（LTV/CAC > 2）

**估值参考：** 5000 万 - 2 亿

**投资人会问什么：**
- 「你的商业模式是什么？」
- 「获客成本（CAC）是多少？」
- 「用户终身价值（LTV）是多少？」
- 「市场规模（TAM）有多大？」

---

### B 轮（Series B）

```
阶段：模式验证成功，需要快速扩张
金额：1 亿 -5 亿
投资人：VC、成长型基金
用途：市场扩张、团队扩充、技术升级
```

**核心任务：** 证明「可以快速复制」

**关键指标：**
- 收入快速增长（月环比 > 30%）
- 单位经济模型健康（LTV/CAC > 3）
- 市场份额开始领先
- 净收入留存率（NRR）> 100%

**估值参考：** 2 亿 - 10 亿

**投资人会问什么：**
- 「你的增长引擎是什么？」
- 「怎么保证增长质量？」
- 「竞争对手在做什么？」
- 「国际化有机会吗？」

---

### C 轮（Series C）

```
阶段：行业领先，准备上市
金额：5 亿 -20 亿+
投资人：PE、大型 VC、战略投资人
用途：进一步扩张、并购、准备 IPO
```

**核心任务：** 证明「能成为行业龙头」

**关键指标：**
- 市场前三
- 持续盈利或清晰盈利路径
- IPO 可行性
- 国际化进展

**估值参考：** 10 亿 - 100 亿+

**投资人会问什么：**
- 「你的护城河是什么？」
- 「IPO 时间表？」
- 「国际化战略？」
- 「并购机会？」

## 为什么要分轮次融资？

很多创始人会问：**为什么不一次性融够所有钱？**

原因有三个：

### 1. 投资人限制

> 不同基金只能投特定阶段。种子基金不能投 B 轮，PE 基金不能投种子轮。

**举例：**
- 种子基金：通常只投 < 500 万的项目
- A 轮基金：通常投 1000 万 -1 亿的项目
- B 轮基金：通常投 1 亿 -5 亿的项目

### 2. 资金使用效率

> 早期公司拿太多钱 = 浪费。因为你还没找到正确的方向，钱多了反而会乱花。

**真实案例：**
> 某公司种子轮融了 1000 万（远超需要的 200 万）。
> 
> 结果：
> - 招了太多人（30 人，实际只需要 10 人）
> - 做了太多功能（10 个，实际只需要 3 个）
> - 18 个月后钱花完，业务没找到方向
> - 倒闭

### 3. 估值和稀释

> 早期估值低，融太多 = 稀释太多股权。分轮次融资，每轮估值更高，稀释更少。

**举例对比：**

| 方案 | 种子轮 | A 轮 | 总融资 | 总稀释 |
|------|--------|------|--------|--------|
| **一次性融** | - | 2000 万@1 亿估值 | 2000 万 | 20% |
| **分轮次融** | 200 万@2000 万估值 | 1800 万@1 亿估值 | 2000 万 | 10% + 15% = 23.5% |

看起来分轮次稀释更多？但注意：
- 种子轮 200 万帮你验证了方向
- A 轮估值从 2000 万涨到 1 亿，证明了你做对了
- 如果一次性融 2000 万@1 亿估值，你可能做不到这个估值

## 融资全流程

### Step 1：准备阶段（2-4 周）

```
── 完善产品/数据
│   └── 确保关键指标健康（留存、增长、变现）
│
├── 准备 BP（商业计划书）
│   ├── 10-15 页 PPT
│   ├── 包含：问题、解决方案、市场、产品、团队、财务
│   └── 重点：突出数据和增长
│
├── 确定目标投资人
│   ├── 找 20-50 个合适的投资人
│   └── 优先找：投过同赛道、同阶段的
│
└── 找 FA（财务顾问）
    ├── FA 帮你对接投资人、谈判条款
    ── FA 费用：融资额的 3-5%
```

### Step 2：路演阶段（4-8 周）

```
├── 见 20-50 个投资人
│   ├── 每次会议 30-60 分钟
│   └── 准备 10 分钟演示 + 20 分钟问答
│
├── 收到 3-5 个 TS（投资意向书）
│   ├── TS 包含：估值、金额、条款
│   └── 选择最优条款（不是最高估值）
│
└── 签署 TS
    ├── TS 不具法律约束力（除了排他条款）
    └── 签署后进入尽调
```

### Step 3：尽调阶段（4-8 周）

```
├── 投资人做业务尽调
│   ├── 用户访谈
│   ├── 竞品分析
│   └── 市场验证
│
├── 投资人做法务尽调
│   ├── 公司架构
│   ├── 知识产权
│   ── 合同审查
│
└── 投资人做财务尽调
    ├── 财务数据审计
    ├── 收入确认
    ── 成本结构
```

### Step 4：签约阶段（2-4 周）

```
├── 签署 SHA（股东协议）
│   ├── 包含：股权比例、投票权、退出机制
│   ── 请专业律师审核
│
├── 完成工商变更
│   └── 更新股东名册、章程备案
│
── 钱到账
    └── 通常分 1-2 次打款
```

## 估值怎么算？

### 早期公司（种子/A 轮）

**方法：可比公司法**

```
找 3-5 个类似阶段、类似赛道的公司
看他们融资时的估值
取中位数作为参考
```

**举例：**
- 公司 A（同赛道）：种子轮估值 3000 万
- 公司 B（同赛道）：种子轮估值 5000 万
- 公司 C（同赛道）：种子轮估值 4000 万
- **你的估值参考：4000 万（中位数）**

### 成长期公司（B/C 轮）

**方法：收入倍数法**

```
估值 = 年收入 × 倍数

倍数参考：
- SaaS：5-15x
- 电商：1-3x
- 硬件：0.5-2x
```

**举例：**
- SaaS 公司年收入 5000 万
- 倍数取 10x
- **估值 = 5 亿**

### 成熟公司（C 轮后）

**方法：DCF（现金流折现）**

```
预测未来 5 年现金流
用折现率（通常 10-20%）折算到现在
```

这个方法比较复杂，通常由专业 FA 或投行来做。

## 常见坑

### 1. 估值过高

> 估值太高 = 下一轮融资困难（投资人觉得贵）

**建议：** 估值合理偏低，给下一轮留空间。

### 2. 稀释过多

> 每轮稀释 15-25% 是合理的。如果单轮稀释 > 30%，说明你议价能力太弱。

**建议：** 多拿几个 TS，互相竞价。

### 3. 条款陷阱

> 注意对赌条款、清算优先权、反稀释条款。

**建议：** 请专业律师审核，不要省这个钱。

### 4. 融资节奏错误

> 太早融资（没数据）→ 估值低、条款差
> 太晚融资（钱快花完）→ 议价能力弱

**建议：** 在公司数据最好的时候融资，而不是钱快花完的时候。

## 一句话总结

> **融资不是目的，是手段。每一轮钱都应该帮你到达下一个里程碑。**
>
> **种子轮：证明想法 → 天使轮：证明有人用 → A 轮：证明商业模式 → B 轮：证明可复制 → C 轮：证明能上市。**
