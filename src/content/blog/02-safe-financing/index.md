## 从一个真实场景说起

2013 年，Y Combinator（全球最著名的创业孵化器）发现一个问题：

> 早期创业融资太复杂了。
>
> 创始人要花几周时间和投资人谈判估值，花几万块律师费起草协议，最后可能因为一个条款谈崩而错过融资窗口。

YC 的合伙人 Carolynn Levy 想出了一个方案：

> **能不能做一个标准化的、5 页纸的融资协议？不用谈判估值，不用复杂条款，签完就拿钱。**

这就是 **SAFE（Simple Agreement for Future Equity）** 的诞生背景。

**到今天，SAFE 已经成为硅谷早期创业最流行的融资工具。** Airbnb、Dropbox、Reddit 早期都用过类似工具。

---

## SAFE 是什么？

### 一句话解释

> 投资人现在给你钱，未来融资时按**更优惠的价格**自动转换成股份。

### 拆解理解

把 SAFE 拆成三部分理解：

**1. Simple（简单）**
- 标准模板 5-6 页
- 律师费极低（甚至可以用 YC 的免费模板）
- 签约到打款最快 1 周

**2. Agreement（协议）**
- 不是股份，不是债券，是一份「未来换股的协议」
- 投资人现在不是股东，没有投票权
- 公司没有还款义务

**3. Future Equity（未来股权）**
- 股份不是现在给的，是未来融资时自动转换的
- 转换价格比下一轮投资人更优惠（通过估值上限或折扣率）

### 完整流程

```
时间线：
│
── T0：签 SAFE
│   ├── 投资人给公司 100 万
│   ├── 公司不给股份，只给一份协议
│   └── 投资人不是股东，是「未来的股东」
│
── T1：下一轮融资（比如 A 轮）
│   ├── 公司估值 5000 万
│   ├── SAFE 自动转换为股份
│   └── 转换价格 = min(估值上限, 折扣后价格)
│
── T2：投资人成为正式股东
    ├── 有投票权
    ├── 有分红权
    └── 可以参与后续决策
```

## 为什么创始人喜欢 SAFE？

### 1. 延迟估值——不用现在纠结「公司值多少」

**早期估值的困境：**
- 创始人觉得公司值 1 亿（毕竟未来市场很大）
- 投资人觉得公司值 3000 万（毕竟还没收入）
- 双方僵持，融资搁置

**SAFE 的解决方案：**
> 现在不谈估值，等下一轮有专业投资人定价时再算。

### 2. 文件简单——律师费从 5 万降到 5000

**传统融资协议：**
- 20-30 页
- 律师费 3-5 万
- 谈判周期 2-4 周

**SAFE：**
- 5-6 页
- 律师费 3000-5000
- 签约周期 3-7 天

### 3. 快速成交——不错过融资窗口

创业融资有个「窗口期」：
- 投资人对你感兴趣 → 必须在 2-4 周内成交
- 拖久了 → 投资人兴趣下降 → 融资失败

**SAFE 让你能在窗口期内快速成交。**

### 4. 无到期日——没有「还不了钱」的压力

和可转债不同，SAFE 没有到期日。公司不会因为「到期还不了钱」而被迫清算。

---

## 为什么投资人喜欢 SAFE？

### 1. 低价入场——通过折扣率或估值上限拿更便宜的股份

**估值上限机制：**

```
举例：
SAFE 估值上限 = $500 万
下一轮估值 = $1000 万

投资人按 $500 万估值转换 → 获得 2 倍股份
（同样的钱，拿到比下一轮投资人多一倍的股份）
```

**折扣率机制：**

```
举例：
折扣率 = 20%
下一轮股价 = $1/股

SAFE 投资人按 $0.8/股转换 → 同样金额多拿 25% 股份
```

### 2. 简单高效——不用做复杂尽调

早期投资的风险本身就高，做 3 个月尽调没必要。SAFE 让投资人可以快速决策。

### 3. 自动转换——不需要额外操作

下一轮融资时，SAFE 自动变成股份，投资人不需要再做任何事。

## SAFE vs 可转债：到底有什么区别？

这是最常见的问题。两者看起来很像，但有几个关键区别：

| 维度 | SAFE | 可转债 |
|------|------|--------|
| **到期日** | ✗ 没有 | ✓ 有（通常 18-24 个月） |
| **利息** | ✗ 没有 | ✓ 有（通常 5-8%） |
| **还款义务** | ✗ 没有 | ✓ 到期必须还本付息 |
| **破产清算顺序** | 排在债权人之后 | 本身就是债权人，优先级更高 |
| **风险** | 如果公司永不融资，投资人可能血本无归 | 即使不融资，到期也要还钱 |

### 一句话总结区别

> **SAFE 是「赌未来」，可转债是「保底 + 赌未来」。**

- 如果你对公司未来非常有信心 → SAFE（成本低）
- 如果你想给投资人一些保障 → 可转债（有利息和到期日）

## 关键参数详解

### 1. 估值上限（Valuation Cap）

**定义：** 投资人能获得的**最高估值**。

**为什么重要：**
- 估值上限越低 → 投资人转换时拿的股份越多 → 创始人稀释越多
- 估值上限越高 → 投资人收益越小 → 创始人稀释越少

**举例：**

```
SAFE 投资：100 万
估值上限：500 万

下一轮融资估值：2000 万

投资人转换股份 = 100 万 / 500 万 = 20%
（而不是 100 万 / 2000 万 = 5%）

投资人以 500 万估值拿到 20% 股份，而不是 5%。
```

**谈判建议：**
- 创始人：估值上限设为当前合理估值的 1.3-1.5 倍
- 投资人：估值上限设为当前合理估值的 0.8-1 倍

### 2. 折扣率（Discount Rate）

**定义：** 投资人比下一轮投资者**少付的百分比**。

**举例：**

```
折扣率：20%
下一轮股价：$1/股

SAFE 投资人按 $0.8/股转换
同样 100 万投资：
- 下一轮投资人：拿到 100 万股
- SAFE 投资人：拿到 125 万股（多 25%）
```

### 3. 四种结构——哪种对你最有利？

| 结构 | 说明 | 对谁更有利 |
|------|------|-----------|
| **仅估值上限** | 只有 Cap，没有折扣 | 投资人（高增长时收益大） |
| **仅折扣率** | 只有折扣，没有 Cap | 创始人（限制投资人收益） |
| **Cap + 折扣** | 两者都有，取更优者 | 投资人（双重保护） |
| **MFN 条款** | Most Favored Nation：后续给更好条件时，早期投资人自动匹配 | 投资人（保底权益） |

**创始人建议：**
> 争取「仅折扣率」或「仅估值上限」，避免「Cap + 折扣」双重条款。

## 转换场景：什么时候 SAFE 会变成股份？

### 场景一：下一轮融资（最常见）

```
触发条件：公司完成股权融资（通常 > 估值上限）

转换方式：
SAFE 自动转换为优先股
转换价格 = min(估值上限对应价格, 折扣后价格)

举例：
估值上限 = $500 万，折扣 = 20%
下一轮估值 = $1000 万，股价 = $1/股

按估值上限：$0.5/股
按折扣：$0.8/股

取更优者（对投资人）：$0.5/股
```

### 场景二：公司被收购

```
触发条件：公司被并购，但不做 IPO

投资人选择：
A. 拿现金退出（本金 + 约定回报，通常 1-2 倍）
B. 转换为普通股参与分配

建议：选 A（现金落袋为安）
```

### 场景三：公司清算/倒闭

```
触发条件：公司破产清算

清偿顺序：
1. 债权人（银行、供应商）
2. SAFE 投资人（通常无优先权）
3. 普通股股东（创始人）

现实：SAFE 投资人通常血本无归
```

## 在中国能用吗？

### 美国：广泛使用

- YC 标准模板，法律框架成熟
- 投资人熟悉，创始人熟悉
- 法院有判例支持

### 中国：不常见

**原因：**
- 法律框架不完善（SAFE 在中国法律体系下定位模糊）
- 投资人不熟悉
- 工商登记不方便

**中国创业者的替代方案：**

> **用「可转债 + 估值上限」模拟 SAFE 效果**
>
> 设定一个合理的到期日（18-24 个月）和利率（5-8%），同时加入估值上限条款。

这样既给了投资人保障（到期还钱），又实现了 SAFE 的核心功能（延迟估值）。

## 注意事项：避坑指南

### 对创始人

#### 1. 估值上限不要设太低

**错误做法：** 为了快速拿到钱，接受很低的估值上限。
**后果：** 公司估值暴涨后，投资人以极低成本拿大量股份 → 创始人被严重稀释。

**建议：** 估值上限比当前合理估值高 30-50%。

#### 2. 警惕「Cap + 折扣」双重条款

**问题：** 投资人两头占便宜——估值上限保护下限，折扣率保证额外收益。
**建议：** 谈判时争取只保留一个。

#### 3. SAFE 不是「免费的钱」

**误解：** SAFE 没有到期日、没有利息 = 免费。
**真相：** 只是延迟了估值讨论。下一轮融资时，所有 SAFE 会一起转换，可能造成大幅稀释。

**举例：**
```
公司发了 5 个 SAFE，总共 500 万
估值上限都是 500 万

下一轮融资估值 5000 万

5 个 SAFE 一起转换 = 500 万 / 500 万 = 100% 股份？？

不对！是 500 万 / (5000 万 + 500 万) = 9.1%

但创始人可能以为只稀释了 5-10%，结果发现稀释了 20%+
```

### 对投资人

#### 1. SAFE 没有到期日

**风险：** 如果公司一直不融资，你的钱可能永远「悬在空中」。
**建议：** 加入「到期自动转换」或「回购条款」。

#### 2. 没有投票权

**风险：** 转换前不是股东，对公司决策无影响力。
**建议：** 完全依赖创始人的诚信和能力——所以要投对人。

---

## 一句话总结

> **SAFE 让早期融资变得简单，但「简单」的代价是「模糊」——估值、稀释、退出都在未来才清晰。**
>
> **创始人：用 SAFE 快速拿到钱，但要注意估值上限和稀释计算。**
>
> **投资人：用 SAFE 快速下注，但要确保有退出保障。**
