## SAFE 是什么？

**SAFE** = Simple Agreement for Future Equity（未来股权简单协议）

由 **Y Combinator** 在 2013 年推出，是硅谷早期创业圈最流行的融资工具之一。

### 一句话解释

> 投资人现在给你钱，未来融资时按**更低的价格**自动转换成股份。

不需要现在讨论公司值多少钱，也不需要复杂的法律文件。

---

## 为什么创始人喜欢 SAFE？

| 优势 | 说明 |
|------|------|
| **延迟估值** | 不用在早期纠结「公司值多少」，等下一轮融资时再定 |
| **文件简单** | 标准模板 5-6 页，律师费极低 |
| **快速成交** | 没有复杂的谈判，签完就拿钱 |
| **无到期日** | 不像可转债有还款期限，没有「还不了钱」的压力 |

---

## 为什么投资人喜欢 SAFE？

| 优势 | 说明 |
|------|------|
| **低价入场** | 通过折扣率或估值上限，以低于后续轮次的价格拿到股份 |
| **简单高效** | 不需要做复杂的尽职调查和估值分析 |
| **自动转换** | 下一轮融资时自动变成股份，无需额外操作 |

---

## SAFE vs 可转债

| 维度 | SAFE | 可转债 |
|------|------|--------|
| **到期日** | ❌ 没有 | ✅ 有（通常 18-24 个月） |
| **利息** | ❌ 没有 | ✅ 有（通常 5-8%） |
| **还款义务** | ❌ 没有 | ✅ 到期必须还本付息 |
| **破产清算顺序** | 排在债权人之后 | 本身就是债权人，优先级更高 |
| **风险** | 如果公司永不融资，投资人可能血本无归 | 即使不融资，到期也要还钱 |

### 核心区别

> **SAFE 是「赌未来」，可转债是「保底 + 赌未来」。**

---

## 关键参数

### 1. 估值上限（Valuation Cap）

投资人能获得的**最高估值**。

```
举例：
SAFE 估值上限 = $500 万
下一轮估值 = $1000 万

投资人按 $500 万估值转换 → 获得 2 倍股份
```

### 2. 折扣率（Discount Rate）

投资人比下一轮投资者**少付的百分比**。

```
举例：
折扣率 = 20%
下一轮股价 = $1/股

SAFE 投资人按 $0.8/股转换 → 同样金额多拿 25% 股份
```

### 3. 四种结构

| 结构 | 说明 | 对谁更有利 |
|------|------|-----------|
| **仅估值上限** | 只有 Cap，没有折扣 | 投资人（高增长时收益大） |
| **仅折扣率** | 只有折扣，没有 Cap | 创始人（限制投资人收益） |
| **Cap + 折扣** | 两者都有，取更优者 | 投资人（双重保护） |
| **MFN 条款** | Most Favored Nation：后续给更好条件时，早期投资人自动匹配 | 投资人（保底权益） |

## 转换场景

### 场景一：下一轮融资

```
SAFE 自动转换为优先股
转换价格 = min(估值上限对应价格, 折扣后价格)
```

### 场景二：公司被收购

```
投资人可以选择：
A. 拿现金退出（本金 + 约定回报）
B. 转换为普通股参与分配
```

### 场景三：公司清算/倒闭

```
投资人排在债权人之后
只能拿回剩余资产中的本金部分
```

## 在中国能用吗？

| 地区 | 情况 |
|------|------|
| **美国** | 广泛使用，YC 标准模板，法律框架成熟 |
| **中国** | 不常见，法律框架不完善，建议用可转债替代 |

### 中国创业者的替代方案

> **用「可转债 + 估值上限」模拟 SAFE 效果**
>
> 设定一个合理的到期日和利率，同时加入估值上限条款。

---

## 注意事项

### 对创始人

1. **估值上限不要设太低**
   - 太低 = 投资人以极低成本拿大量股份
   - 建议：比当前合理估值高 30-50%

2. **警惕「Cap + 折扣」双重条款**
   - 投资人两头占便宜
   - 谈判时争取只保留一个

3. **SAFE 不是「免费的钱」**
   - 只是延迟了估值讨论
   - 下一轮融资时，所有 SAFE 会一起转换，可能造成大幅稀释

### 对投资人

1. **SAFE 没有到期日**
   - 如果公司一直不融资，你的钱可能永远「悬在空中」
   - 建议加入「到期自动转换」或「回购条款」

2. **没有投票权**
   - 转换前不是股东，对公司决策无影响力
   - 完全依赖创始人的诚信和能力

---

## 一句话总结

> **SAFE 让早期融资变得简单，但「简单」的代价是「模糊」——估值、稀释、退出都在未来才清晰。**
