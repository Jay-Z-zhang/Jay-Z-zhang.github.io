2025 年，AI 不再是「辅助工具」，而是「工作伙伴」。这篇文章分享我如何用 AI Agent 重构自己的 PM 工作流。

## Agent 架构流程

```
调研 → 需求定义 → 方案设计 → 原型生成 → 开发协作 → 数据分析 → 复盘
```

每个环节都有对应的 AI Agent 介入：

| 环节 | Agent 角色 | 工具 |
|------|-----------|------|
| 调研 | 信息搜集 + 竞品分析 | Claude + WebSearch |
| 需求 | PRD 生成 + 用户故事 | Claude Code |
| 原型 | 线框图 + 交互设计 | Vibe Coding |
| 数据 | SQL 生成 + 报表分析 | BigData MCP |
| 复盘 | 数据归因 + 报告生成 | AI 辅助 |

## 关键心得

1. **Prompt 质量决定产出质量** — 描述需求的能力 > 写代码的能力
2. **人机协作而非替代** — AI 做 80% 的重复工作，人做 20% 的判断
3. **迭代速度是核心优势** — 以前一周的调研，现在一天搞定
