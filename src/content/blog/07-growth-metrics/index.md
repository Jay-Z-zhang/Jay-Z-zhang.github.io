## 为什么需要指标体系？

很多团队的问题不是「没有数据」，而是「数据太多，不知道看哪个」。

- 老板看 DAU
- 产品看留存
- 市场看转化
- 运营看活跃

**每个人看的指标不同，导致决策冲突。**

增长指标体系的作用：**让全公司对「什么是成功」达成共识**。

---

## 指标分层模型

### 第一层：北极星指标（North Star Metric）

**定义：唯一最重要的指标，反映产品核心价值。**

| 公司 | 北极星指标 |
|------|-----------|
| **Facebook** | 月活跃用户数（MAU） |
| **Uber** | 周订单数 |
| **Airbnb** | 预订间夜数 |
| **Spotify** | 听歌时长 |

**选择标准：**
- 反映用户获得的核心价值
- 可操作（团队能影响它）
- 可衡量（能准确计算）

### 第二层：一级指标（Input Metrics）

**定义：直接影响北极星指标的关键驱动因素。**

```
北极星指标 = 周订单数（Uber）

一级指标：
├── 司机供给：活跃司机数
├── 用户需求：叫车请求数
└── 匹配效率：接单率
```

### 第三层：二级指标（Diagnostic Metrics）

**定义：帮助定位问题的诊断指标。**

```
一级指标 = 接单率下降

二级指标：
├── 司机端：在线时长、拒单率
── 用户端：等待时长、取消率
└── 系统端：派单算法成功率
```

### 第四层：健康指标（Health Metrics）

**定义：确保增长不损害用户体验的guardrail指标。**

```
增长指标 = 推送次数增加

健康指标：
├── 退订率 < 5%
├── 投诉率 < 0.1%
└── 日活不受影响
```

## 虚荣指标 vs 可操作指标

### 虚荣指标（Vanity Metrics）

> 看起来很好，但不能指导行动。

| 虚荣指标 | 问题 |
|----------|------|
| **累计注册数** | 不反映活跃和留存 |
| **页面浏览量（PV）** | 不反映用户价值 |
| **下载量** | 不反映激活和留存 |

### 可操作指标（Actionable Metrics）

> 能告诉你「接下来该做什么」。

| 可操作指标 | 价值 |
|-----------|------|
| **7 日留存率** | 反映产品粘性 |
| **激活率** | 反映 onboarding 效果 |
| **付费转化率** | 反映变现能力 |

## 如何搭建指标体系？

### Step 1：定义用户核心价值

**问自己：**
> 用户用我们的产品，最重要的「啊哈时刻」是什么？

| 产品 | 啊哈时刻 |
|------|---------|
| **Facebook** | 添加 10 个好友 |
| **Uber** | 第一次成功叫到车 |
| **Slack** | 团队发送 2000 条消息 |

### Step 2：选择北极星指标

**公式：**
```
北极星指标 = 用户获得核心价值的频率
```

**示例：**
- Facebook：周活跃用户（反映社交频率）
- Uber：周订单数（反映出行频率）
- Slack：团队消息数（反映协作频率）

### Step 3：拆解一级指标

**方法：用户旅程地图**

```
用户旅程：注册 → 激活 → 留存 → 付费 → 推荐

对应一级指标：
├── 注册转化率
├── 激活率（完成啊哈时刻）
├── 7 日/30 日留存率
── 付费转化率
└── K 因子（推荐系数）
```

### Step 4：定义健康指标

**原则：**
> 每个增长动作，都要有对应的健康指标约束。

| 增长动作 | 健康指标 |
|----------|---------|
| **增加推送** | 退订率、投诉率 |
| **提高价格** | 流失率、NPS |
| **扩大投放** | CAC、回本周期 |

## 不同阶段的指标重点

### 0-1 阶段（产品验证期）

**核心指标：留存率**

```
目标：证明有人愿意持续用

关键指标：
- 7 日留存 > 40%
- 用户访谈 NPS > 50
- 自然增长占比 > 30%
```

### 1-10 阶段（增长期）

**核心指标：获客效率**

```
目标：找到可复制的获客渠道

关键指标：
- CAC < LTV/3
- 渠道 ROI > 1
- 月增长 > 20%
```

### 10-100 阶段（规模期）

**核心指标：单位经济模型**

```
目标：证明规模化后仍能盈利

关键指标：
- LTV/CAC > 3
- 回本周期 < 12 个月
- 毛利率 > 60%
```

## 常见错误

### 1. 指标太多

> **聚焦 3-5 个核心指标，而不是看 30 个仪表盘。**

### 2. 只看结果指标

> **结果指标（如收入）告诉你「发生了什么」，但不告诉你「为什么」。**
> 
> 必须搭配过程指标（如转化率、留存率）。

### 3. 忽略健康指标

> **增长不能以牺牲用户体验为代价。**
> 
> 推送多了，活跃可能上升，但退订率也会上升。

### 4. 对标错误

> **不要盲目对标大公司的指标。**
> 
> Facebook 的 DAU 对你没有参考价值，你的阶段和产品不同。
