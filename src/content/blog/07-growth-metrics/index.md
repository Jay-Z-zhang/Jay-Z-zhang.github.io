## 从一个真实场景说起

某创业公司的周会上：

- **老板**：「DAU 怎么又降了？」
- **产品**：「留存率提升了啊！」
- **市场**：「转化率创新高！」
- **运营**：「活跃用户数在增长！」

**每个人看的指标不同，得出的结论也不同。**

这就是没有统一指标体系的后果：**团队各自为战，决策冲突。**

增长指标体系的作用：**让全公司对「什么是成功」达成共识**。

## 指标分层模型

### 第一层：北极星指标（North Star Metric）

**定义：唯一最重要的指标，反映产品核心价值。**

| 公司 | 北极星指标 | 为什么选这个 |
|------|-----------|-------------|
| **Facebook** | 月活跃用户数（MAU） | 社交网络的价值在于有多少人用 |
| **Uber** | 周订单数 | 出行平台的价值在于完成多少订单 |
| **Airbnb** | 预订间夜数 | 住宿平台的价值在于多少间夜被预订 |
| **Spotify** | 听歌时长 | 音乐平台的价值在于用户听了多久 |

**选择标准：**
- 反映用户获得的核心价值
- 可操作（团队能影响它）
- 可衡量（能准确计算）

### 第二层：一级指标（Input Metrics）

**定义：直接影响北极星指标的关键驱动因素。**

**以 Uber 为例：**

```
北极星指标 = 周订单数

一级指标：
── 司机供给：活跃司机数
├── 用户需求：叫车请求数
└── 匹配效率：接单率
```

**为什么这些是一级指标？**
- 活跃司机数 ↑ → 接单率 ↑ → 订单数 ↑
- 叫车请求数 ↑ → 订单数 ↑
- 接单率 ↑ → 订单数 ↑

### 第三层：二级指标（Diagnostic Metrics）

**定义：帮助定位问题的诊断指标。**

```
一级指标 = 接单率下降

二级指标：
├── 司机端：在线时长、拒单率
── 用户端：等待时长、取消率
└── 系统端：派单算法成功率
```

### 第四层：健康指标（Health Metrics）

**定义：确保增长不损害用户体验的 guardrail 指标。**

```
增长动作 = 增加推送次数

健康指标：
├── 退订率 < 5%
├── 投诉率 < 0.1%
└── 日活不受影响
```

## 虚荣指标 vs 可操作指标

### 虚荣指标（Vanity Metrics）

> 看起来很好，但不能指导行动。

| 虚荣指标 | 为什么虚荣 | 更好的替代 |
|----------|-----------|-----------|
| **累计注册数** | 不反映活跃和留存 | 月活跃用户数（MAU） |
| **页面浏览量（PV）** | 不反映用户价值 | 核心功能使用率 |
| **下载量** | 不反映激活和留存 | 7 日留存率 |

### 可操作指标（Actionable Metrics）

> 能告诉你「接下来该做什么」。

| 可操作指标 | 价值 | 行动指导 |
|-----------|------|---------|
| **7 日留存率** | 反映产品粘性 | < 30% → 优化 onboarding |
| **激活率** | 反映 onboarding 效果 | < 50% → 简化首次使用流程 |
| **付费转化率** | 反映变现能力 | < 5% → 优化定价或功能 |

## 如何搭建指标体系？

### Step 1：定义用户核心价值

**问自己：**
> 用户用我们的产品，最重要的「啊哈时刻」是什么？

| 产品 | 啊哈时刻 | 说明 |
|------|---------|------|
| **Facebook** | 添加 10 个好友 | 有足够多好友才能看到有趣内容 |
| **Uber** | 第一次成功叫到车 | 体验到「随叫随到」的便利 |
| **Slack** | 团队发送 2000 条消息 | 深度使用后才离不开 |

### Step 2：选择北极星指标

**公式：**
```
北极星指标 = 用户获得核心价值的频率
```

**示例：**
- Facebook：周活跃用户（反映社交频率）
- Uber：周订单数（反映出行频率）
- Slack：团队消息数（反映协作频率）

### Step 3：拆解一级指标

**方法：用户旅程地图**

```
用户旅程：注册 → 激活 → 留存 → 付费 → 推荐

对应一级指标：
├── 注册转化率
├── 激活率（完成啊哈时刻）
├── 7 日/30 日留存率
── 付费转化率
└── K 因子（推荐系数）
```

### Step 4：定义健康指标

**原则：**
> 每个增长动作，都要有对应的健康指标约束。

| 增长动作 | 健康指标 | 阈值 |
|----------|---------|------|
| **增加推送** | 退订率 | < 5% |
| **提高价格** | 流失率 | < 10% |
| **扩大投放** | CAC | < LTV/3 |

## 不同阶段的指标重点

### 0-1 阶段（产品验证期）

**核心指标：留存率**

```
目标：证明有人愿意持续用

关键指标：
- 7 日留存 > 40%
- 用户访谈 NPS > 50
- 自然增长占比 > 30%
```

**为什么留存最重要？**
> 如果用户来了就走，说明产品没价值。这时候做任何增长都是浪费。

### 1-10 阶段（增长期）

**核心指标：获客效率**

```
目标：找到可复制的获客渠道

关键指标：
- CAC < LTV/3
- 渠道 ROI > 1
- 月增长 > 20%
```

**为什么获客效率最重要？**
> 产品已经验证，现在要快速获客。但获客成本不能太高，否则规模越大亏越多。

### 10-100 阶段（规模期）

**核心指标：单位经济模型**

```
目标：证明规模化后仍能盈利

关键指标：
- LTV/CAC > 3
- 回本周期 < 12 个月
- 毛利率 > 60%
```

**为什么单位经济模型最重要？**
> 规模化需要大量资金。如果单位经济模型不健康，融越多钱亏越多。

## 常见错误

### 1. 指标太多

> **聚焦 3-5 个核心指标，而不是看 30 个仪表盘。**

**为什么？**
- 指标太多 → 注意力分散 → 不知道优先做什么
- 3-5 个指标 → 全公司对齐 → 高效执行

### 2. 只看结果指标

> **结果指标（如收入）告诉你「发生了什么」，但不告诉你「为什么」。**

**举例：**
- 收入下降（结果）→ 为什么？
- 因为转化率下降（过程）→ 为什么？
- 因为落地页加载慢（诊断）→ 优化！

**必须搭配过程指标和诊断指标。**

### 3. 忽略健康指标

> **增长不能以牺牲用户体验为代价。**

**举例：**
- 推送多了 → 活跃可能上升，但退订率也会上升
- 价格高了 → 收入可能上升，但流失率也会上升

**每个增长动作都要有健康指标约束。**

### 4. 对标错误

> **不要盲目对标大公司的指标。**

**举例：**
- Facebook 的 DAU 对你没有参考价值
- 你的阶段、产品、用户都不同

**正确做法：**
- 找同阶段、同赛道的公司对标
- 或者和自己的历史数据对标
