PV
页面浏览量
—
口径：统计周期内 page_view 事件次数之和。一次页面加载记 1 次；刷新会再记。不是去重人数。
Σ DAU
日活加总
—
口径：按 UTC 自然日、IP 哈希去重后的每日独立访问者，再把各天相加。跨天回访会重复计入，不是周期 UV。
Resume Events
简历工具事件次数
—
口径：简历工具全部主事件之和（导出、分享、打开/提交 AI 等）。打开与提交分别计数，未做用户去重。
AI Calls
AI 接口调用次数
—
口径：Cloudflare Worker 转发 DeepSeek 的服务端请求数，与前端「开始润色」不是同一指标。含失败。

每日页面浏览量 Daily PV

横轴为 UTC 日期（左旧右新）。柱高 = 当日 page_view 次数。悬停可看当天绝对值。

访问来源域名 Referrer Host

仅在 page_view 时记录 document.referrer 的主机名。站内跳转、直接打开、微信等无 referrer 的场景会计入「直接/不可识别」。不能当作完整 UTM 渠道。

落地页浏览量 PV by Path

维度是 URL 路径（不含 query / hash）。同一路径多次打开会累加。占比 = 该路径 PV / 本表最大项，不是占全站 PV 的份额。

简历工具事件明细 Resume Event Count

客户端在用户完成对应操作后上报。带维度的子键（如 resume_template:classic）是拆解，与主事件同时计数，下表会分开列出。

简历工具漏斗（打开 → 提交） Open → Submit

提交率 = 提交次数 / 打开次数。分母是打开弹窗次数，不是 PV。未打开直接失败的不进入分母。提交不代表模型调用成功（成功以下方 AI 接口为准）。

AI 接口用量 Server-side AI Calls

数据源：Worker 在转发 DeepSeek 后写入。polish / rewrite / import 对应润色、改写、导入三类。Tokens 为模型返回的 total_tokens 之和。错误次数含 4xx/5xx。受每 IP 每天 30 次上限影响，达上限后不会再增加调用。

指标与口径说明

时区：全部按 UTC 自然日 切天（不是北京时间）。保留期：约 60 天（KV TTL）。并发写入 KV 可能少计。单 IP 每小时最多计入 120 条前端事件，超限丢弃。不采集简历正文、姓名、邮箱等 PII。
